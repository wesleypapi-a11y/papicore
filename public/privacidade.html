Política de Privacidade

Última atualização: agosto de 2026.

Este é um modelo inicial de Política de Privacidade, com linguagem genérica. Ele deve ser revisado por um profissional jurídico antes de ser considerado definitivo.

1. Dados coletados pelo site

Ao preencher o formulário de contato comercial em nosso site, coletamos os dados informados voluntariamente por você: nome, nome da empresa, WhatsApp, cidade, quantidade de unidades, plano de interesse e a mensagem enviada.

2. Finalidade do tratamento

Os dados enviados pelo formulário são usados exclusivamente para que a equipe do PapiCore possa entrar em contato, apresentar a plataforma e conduzir o processo comercial. Não utilizamos esses dados para outras finalidades sem o seu consentimento.

3. Armazenamento

Os dados do formulário de contato são armazenados em banco de dados próprio da plataforma, com acesso restrito à equipe do PapiCore, e ficam disponíveis apenas no Painel do Desenvolvedor, protegido por autenticação.

4. Cookies

Este site utiliza apenas os recursos essenciais de armazenamento local do navegador necessários para o seu funcionamento (por exemplo, preferências de exibição). Não utilizamos cookies de rastreamento publicitário de terceiros.

5. Compartilhamento de dados

Não vendemos nem compartilhamos os dados coletados pelo formulário de contato com terceiros para fins de marketing.

6. Seus direitos

  • Solicitar a confirmação de que seus dados foram recebidos;
  • Solicitar a correção de dados incorretos;
  • Solicitar a exclusão dos seus dados de contato.

7. Contato

Para solicitações relacionadas aos seus dados, utilize o formulário de contato disponível na página inicial ou os canais de contato divulgados no rodapé do site.
